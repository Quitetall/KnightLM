# Intent

Ship the dedicated Assistant tab: left session/board rail, center board, right chat with
composer and context inspector. The window is a thin Leptos shell over `rbc-ai`; it streams,
persists, inspects and reviews, and it never owns chess rules or provider logic.

Out of scope: match/tournament UI (W-05/W-06), study editor (W-07), compare (W-08), MCP
transport (W-09).

# Basis

- Frontend is already split: `lib.rs`, `model.rs`, `views/`; use the `AppCtx` pattern.
- Decisions: `Assistant` sidebar tab; workspace kind `assistant`; one session rail; extra
  tabs can pin sessions; left rail/center board/right chat; board strip + left-rail boards;
  context inspector with hash/replay; provider settings; keyring.
- `rbc-ai` protocol + SSE + approvals from W-03.

# Work Order

Deliverables (packages PKG-030..PKG-037):

1. Assistant tab + workspace kind + session rail (new/rename/archive/search) + restore.
2. Center board + board strip + left-rail board tree + active/target markers + focus-board.
3. Transcript: streaming content, reasoning toggle, tool/retry/action cards, usage, errors.
4. Composer: slash commands, `@`-mentions, attachments (PGN/FEN/image), context chips, model
   picker, stop/steer/regenerate, command palette, keybinds.
5. Context inspector: sections, token counts, included/truncated, canonical prompt, hash,
   pin/live, replay/diff.
6. Provider settings: list/add/test, base URL, keyring, localhost scan, capability metadata.
7. Approval/changeset UI: pending queue, diff, approve all/selected, deny, auto-approve
   scopes.
8. i18n (en/es), a11y labels/live regions, empty/error states.

Seams:

- The tab reads `rbc-ai` protocol DTOs and SSE; no direct SQLite.
- Board actions from tool events go through the board repository API; no local mutation.
- The Analysis dock keeps working through `/api/chat` compatibility.

Autonomy and escalation:

inspector contract. The performer owns component structure and styling within the existing
design system.

Rollback:

## Obligations

### OBL-001: a turn streams into the transcript as it happens, and can be stopped

- **scope:** the Assistant view consuming the session SSE stream, and the Stop
  control. It says nothing about a slow provider beyond the cancellation message.
- **evidence:** `frontend/tests/cdp/cdp_ai_stream.js` (`AI_STREAM_PASS`): a partial
  delta is visible while the turn runs, the button reads Stop, and after stopping the
  turn reports "the turn was cancelled".

### OBL-002: the session rail lists, renames, archives and pins conversations

- **scope:** those rail actions against stored sessions.
- **evidence:** `cdp_ai_rail.js` (`AI_RAIL_PASS`), `cdp_ai_rail2.js`, `cdp_ai_pin.js`
  (`AI_PIN_PASS`).

### OBL-003: the context inspector shows what was sent, and says when the board moved

- **scope:** the panel's section list, canonical prompt, hash, replay diff, and the
  Sent/Live toggle. It does not claim the live compile equals the sent one — that is
  exactly what the warning reports.
- **evidence:** `cdp_ai_context.js` (`AI_CONTEXT_PASS`): 4 sections, the sha/token
  header, the canonical prompt, `replay · identical`, and the drift line appearing
  only when the live hash differs from the sent one.

### OBL-004: the board being written to is visible even when it is not on screen

- **scope:** the strip marker, the off-screen badge and its click-to-focus.
- **evidence:** `cdp_cross_board.js` (`AI_CROSS_BOARD_PASS`).

### OBL-005: a conversation outlives a cleared browser

- **scope:** restore after `localStorage.clear()`, and the one-time reset notice.
- **evidence:** `cdp_session.js` (`AI_SESSION_PASS`).
