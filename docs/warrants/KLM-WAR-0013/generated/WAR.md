# Intent

Build `rbc-context`, the pure compiler that produces the exact input an agent sees. The same
position, history, config and evidence must produce the same canonical bytes and SHA-256. The
compiler is reusable by chat, play, evaluation and future training; it must not know about
HTTP, SQLite, engines or the UI.

Out of scope: provider calls, tool execution, dataset splits/training loop, UI rendering.

# Basis

- `knightlm-core::state::ContextPacket` already provides a versioned canonical position
  packet (FEN, facts, legal moves, features). Reuse it.
- `knightlm-notation` provides SAN/PGN helpers.
- Decisions: default sections position/legal moves/ASCII; everything configurable; chat
  default board + sibling directory; compare scope adds a cross-workspace directory; rated
  mode pins sampling/tools/engine; deterministic input only.
- Interface fixed with `rbc-ai`: `ContextSpec`, `Evidence`, `Section`, `CompiledContext`.

# Work Order

Deliverables (packages PKG-010..PKG-015):

1. `rbc-context` crate: section model, canonical JSON, rendered prompt, SHA-256, spec/template
   versions, token counts.
2. Position sections: FEN, side, castling/en passant, ASCII, legal moves (sorted SAN+UCI),
   history (SAN, clocks when present), annotations/shapes.
3. Optional evidence: engine (binary hash, depth, threads=1, hash), openings, database,
   tablebase, notes, sibling directory, compare directory.
4. Token budget, deterministic truncation (oldest complete turn first), tokenizer abstraction
   with a versioned default estimate; required sections fail closed.
5. CLI: `compile`, `batch`, `validate`, `hash`, `sections`; JSON and JSONL output; optional
   target/eval fields in batch without inventing values.
6. Golden/property tests: exact bytes/hash, cross-platform stability, map-order stability,
   evidence fingerprinting, budget behavior, CLI round-trip.

Seams:

- `rbc-ai` supplies evidence and owns persistence of the compiled context/hash.
- The CLI and library expose the same `CompiledContext` schema.
- No ambient time, locale, randomness or map iteration order in rendered content.

Autonomy and escalation:

Tier T2. Escalate any change to the section ordering, hash input, or default sections. The
performer owns the internal renderer structure and tokenizer implementation.

Rollback:

The crate is additive. If a spec version is wrong, bump `spec_version`; never rewrite an old
hash. Keep old fixtures as regression tests.

# Assurance



## Gate Adequacy

Required at `basic`. **Adversarial question:** how could this look done and not be?
Each obligation pairs a positive claim with a refusal: a stale revision, a locked board, a
missing hash, an unapproved write, or a dropped required section. The package test in
`openwarrant/packages.json` is the executable gate; the obligation text is the contract.


## Obligations

### OBL-001: the same input compiles to the same bytes

- **scope:** one context spec, one input, twenty compilations in one process. It
  does not claim stability across a tokenizer change or a spec revision.
- **evidence:** `same_input_twenty_times_is_byte_identical` and
  `input_json_key_order_does_not_matter` in `crates/context/tests/compile.rs`.

### OBL-002: the hash covers the evidence, not just the words

- **scope:** identical text with a different evidence fingerprint must hash
  differently. Whether that fingerprint is *correct* is out of scope.
- **evidence:** `evidence_fingerprint_changes_hash` (`crates/context/tests/compile.rs`).

### OBL-003: an over-budget compile names the sections it could not fit

- **scope:** the failure path when required sections exceed the budget.
- **evidence:** `required_section_budget_failure_names_sections`
  (`crates/context/tests/compile.rs`).

### OBL-004: the CLI compiles, validates and hashes without a server

- **scope:** `rbc-context` subcommands operating on files. It says nothing about the
  HTTP compile route, which is a different caller of the same library.
- **evidence:** the `knightlm-context` binary's own tests plus `scripts/check_cli.py`
  in the repository's `make check`.
