Ship first-class studies: ordered chapters, a primary board plus additional boards per
chapter, move trees, arrows, annotations, Markdown notes, metadata, draft/publish versions,

changesets. Import/export is portable.

# Work Order

Deliverables (packages PKG-060..PKG-065):
