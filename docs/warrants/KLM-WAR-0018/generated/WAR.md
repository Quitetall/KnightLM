# Intent

Ship first-class studies: ordered chapters, a primary board plus additional boards per
chapter, move trees, arrows, annotations, Markdown notes, metadata, draft/publish versions,
manual locks and progress placeholders. The AI and MCP can author through the same tools and
changesets. Import/export is portable.

Out of scope: Lua lesson runtime (R2), sharing/cloud sync, merge.

- W-03/W-04 provide tools and the Assistant.
- Decisions: study is a standalone object in a Study tab; one primary + additional boards per
  chapter; Markdown; `.rbcstudy` + PGN + Lichess adapter; draft/publish + manual lock;
  per-user progress overlay; AI/MCP authoring with changesets.

# Work Order

Deliverables (packages PKG-060..PKG-065):

1. Study tab/editor: chapter list, add/reorder/duplicate/delete, primary/additional board
   strip, board + move tree + arrows + annotations, Markdown editor/preview, metadata.

   publish; changeset review; immutable/published protection.
6. Tests: CRUD/order, versions, round-trip, progress overlay, authoring changesets.

bundles are self-contained.
