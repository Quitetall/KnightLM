# Version 1 contracts

All Rust wire structs reject unknown fields. `schema_version` is 1. Model-facing
packets have no teacher score/PV fields. The official Lichess shape is decoded
into a separate teacher-only type. Canonical JSON uses sorted object keys and
compact separators; array order is preserved.

## State and compiler

`GameRecord` contains source, game identity, initial six-field FEN, an explicit
`history_complete` assertion and standard UCI moves. A trusted source may define
an analysis setup as its initial position; that does not prove any history before
the setup. The compiler must not infer completeness from a FEN or image.

`GameState` owns the board, independent u32 halfmove/fullmove counters, full
played-move log, and canonical repetition ledger. Fullmove starts at one.
Move application is checked and counter overflow returns an error. Full history
remains in the record; only repetition history is compacted after a pawn move,
capture or loss of castling rights. Earlier positions then cannot recur.

Repetition identity includes piece placement, side, rights, and only legally
usable en passant. A pinned pawn unable to capture en passant does not make a
distinct repetition position. Ledger keys are readable four-field FENs, not
opaque hashes. Counted occurrences include the initial state.

`ContextPacket` contains complete current FEN, completeness marker, repetition
ledger and rule facts. Optional legal choices and derived features are controlled
by the experiment arm. Partial-history packets can be compiled for inspection;
complete-state experiment preparation refuses them. Context overflow is an
error, not silent truncation. Packet size varies with relevant history.

`dead_position: null` means unknown, not false. The v1 recognizer handles only
three elementary material patterns. `terminal_reason: null` therefore means no
terminal condition was established by supported checks. Claimable draws do not
automatically terminate play. Checkmate takes precedence over the 75-move rule.

`BoardObservation` contains image identity and visible piece placement only.
Image prediction is compared against the authoritative ledger. Disagreement is
an explicit error. There is no inferred castling right, clock, side to move, or
repetition history from pixels. This integrity boundary is not a perception model.

## Assistance and evidence

`RuleSession` branches by state index, starting at zero. Every attempted call,
including malformed or illegal requests, consumes budget. Each successful call
simulates one ply on a clone and returns a new branch. The source game is never
mutated. No evaluation score, recommendation, automatic search or tablebase is
available.

`InferenceRequest` separates prompt text from a decoder legality constraint.
This scaffold builds the constraints but does not implement pretrained constrained
decoding. A masked result requires a separate unmasked diagnostic; scores never
equate assisted legality with model knowledge. Diagnostic output tokens are
charged separately. Reports reject over-budget telemetry and undeclared
interventions, but telemetry from a future external adapter remains untrusted
until that adapter is admitted and instrumented.

`RunRecord` retains the game, configuration, exact request and decision. Fixture
checkpoints produce `fixture_only` evidence. Other submitted outputs are
`unverified_external_output`, not proof of a verified inference backend. An
illegal unmasked move is a scored failure, not an exception that erases the trial.
No Elo or semantic-success claim is generated by fixture execution.

Structured `FactClaim`s check move legality, next FEN and current check. Free
prose is unscored, including prose that conflicts with a correct structured
claim. Evaluating free explanations needs a separate validated factuality method.
`SemanticProbe` stores target separately from its prompt. Unaided probe inputs
exclude derived facts; targets are never included by `inference_prompt`.

## Models and ports

`ModelBackend` defines `reset`, `observe` and `generate`. The two-pass orchestrator
resets before observation, after observation (including failure), and after
generation. A fixture checks KV/recurrent/convolution isolation. Actual model
adapters must implement and prove all architecture-specific resets themselves.

The CPU smoke persists a two-weight linear model; its results cannot qualify any
language or multimodal model. `verify-model` always refuses admission until an
actual implementation and architecture-specific evidence exist. Setting a model
revision alone never admits a model.

Python and Mojo are protocol slices. Python validates boundary shape and expands
piece placement. Mojo runs native draw-counter consistency checks, using CPython
for JSON shape/serialization. Neither is an independent full chess rules oracle.

## Deferred interfaces

PGN ingestion must produce normalized `GameRecord`s with explicit provenance,
handle setup positions, and preserve history completeness. Bulk eval ingestion
must stream, cap resources, preserve depth/node metadata and retain cp-versus-mate
semantics. The current in-memory JSONL reader is for bounded fixtures only.

Real training tracks are chess teacher, verified semantics, digital-board vision,
and general language. Their sampling budgets are campaign configuration, not
preselected scientific conclusions. Use held-out game/position families and
visual styles. Real campaign profiles must bind checkpoint revision, data
manifests, tokenizer, code revision, budgets and seeds before scoring.
